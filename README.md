# 🚗 Tesla Website Clone

A fully responsive clone of the Tesla website, built with React, TypeScript, and Vite.

## 🔗 Live Demo

👉 **[View Live Site](https://alinevis-1378.github.io/tesla/)**

## ✨ Features

- 📱 Fully responsive design (mobile, tablet, desktop)
- 🛣️ Dynamic routing with React Router
- 🛒 Shopping cart with add/remove functionality
- 🎨 Modern, clean UI matching Tesla's aesthetic
- 🚀 Automated deployment via GitHub Actions

## 🛠️ Tech Stack

- **React** — UI library
- **TypeScript** — Type safety
- **Vite** — Build tool & dev server
- **React Router** — Client-side routing
- **CSS** — Styling

## 🚀 Getting Started

```bash
git clone https://github.com/alinevis-1378/tesla.git
cd tesla
npm install
npm run dev
